# Working with this repo in Claude Code

When editing prose in a folder where Stilura is running (`draft.md` present, Stilura on `127.0.0.1:3000`–`3010`), follow `skills/stilura/SKILL.md`: voice rules, finding codes, and the localhost API (`GET/PUT /draft`, `POST /review /rewrite /suggest /chat`).

Install the skill: `cp -r skills/stilura ~/.claude/skills/` (user scope) or into `.claude/skills/` (project scope).
