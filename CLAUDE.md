# Working with this repo in Claude Code

When editing prose in a folder where Litura is running (`draft.md` present, Litura on `127.0.0.1:3000`–`3010`), follow `skills/litura/SKILL.md`: voice rules, finding codes, and the localhost API (`GET/PUT /draft`, `POST /review /rewrite /suggest /chat`).

Install the skill: `cp -r skills/litura ~/.claude/skills/` (user scope) or into `.claude/skills/` (project scope).
