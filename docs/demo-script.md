# README demo: a page before email

A 26-second loop. One small draft, three actions. The writer starts the thought, tries different wording and decides what stays. No whole-document rewrite or settings tour.

Use the light theme and a 960 × 560 editor window. Keep the text readable; leave a short pause before accepting each preview.

Start with:

```text
# A page before email

I leave my phone in the kitchen and open my notebook. For ten minutes, I write whatever comes to mind.
```

1. **Continue a thought.** Start a new paragraph and type `It is important to note that the first draft does not have to be`. Pause for `perfect.` to appear as a continuation, then press **Tab**.
2. **Cut the filler.** Select that sentence and press **Cmd/Ctrl+K**. Ask `Make this shorter. Keep the meaning.` Preview a replacement, press **↓** to try another, then **Tab** to keep `A rough first draft is enough.`
3. **Try an ending.** Start a new paragraph. Type `/Add one sentence about rereading this tomorrow.` and press **Enter**. Let the preview finish, press **R** for another take, then **Tab** to keep it.

End on the finished page for two seconds. Loop back to the opening.
